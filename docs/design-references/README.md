# Flowboard landing-page references

These six images are composition references for the public landing page. They are not production screenshots and must not be embedded as substitutes for the real product UI.

The implementation should reproduce their hierarchy, spacing, palette, shape language, and material direction with semantic HTML, CSS Modules, real Flowboard components, and final product captures.

1. [`01-hero.png`](./01-hero.png) - Off-grid hero, public navigation, task-board proof, and tactile planning material
2. [`02-personal-planning.png`](./02-personal-planning.png) - Personal workspace, task views, filtering, drag interaction, and checklist detail
3. [`03-shared-projects.png`](./03-shared-projects.png) - Project board, roles, discussion, and activity context
4. [`04-product-depth.png`](./04-product-depth.png) - Five-cell product-depth composition
5. [`05-real-workflows.png`](./05-real-workflows.png) - Accessibility, permissions, and recoverable updates
6. [`06-closing-cta.png`](./06-closing-cta.png) - Closing conversion moment and credited footer

## Implementation constraints

- Real redesigned application captures replace generated interface imagery before release.
- Generated tactile artifacts may be retained only when they contain no illegible or invented text.
- Marketing copy follows `DESIGN.md` and contains no em dashes or en dashes.
- Product functionality, permissions, and route behavior remain grounded in the repository.
- The section references establish direction, not pixel-perfect mandates. Responsive behavior and accessibility take precedence over matching a static frame.
